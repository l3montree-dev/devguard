# Contributing to DevGuard

Feedback and contributions are very welcome!

Full contributing documentation — including how to set up the project
locally, how we handle issues and pull requests, and where to find
[good first issues](https://github.com/l3montree-dev/devguard/labels/good%20first%20issue) —
now lives on our docs site:

👉 <https://docs.devguard.org/contributing/getting-started/>

## Quick reference

* [Code of Conduct](./CODE_OF_CONDUCT.md) — please read this before contributing.
* [Security policy](./SECURITY.md) — please report vulnerabilities privately rather than opening a public issue.
* [License](./LICENSE.txt) — all contributed source code must be released under the AGPL-3.0 license.
* [Developer Certificate of Origin](./docs/dco.txt) — all contributions must be signed off (`git commit --signoff`), certifying you have the right to submit the patch.
