## provenance sign

Let DevGuard sign SLSA build provenance with the verified identity of the CI job

### Synopsis

Send an in-toto statement with a SLSA v1 provenance predicate to DevGuard for signing.

DevGuard verifies the OIDC workload identity token of the CI job with its issuer and writes the
verified identity into the provenance before signing it:

  predicate.runDetails.builder.id                                         the ci config which ran the build, including the issuer
  predicate.buildDefinition.internalParameters.devguard.workloadIdentity  all claims of the verified token

Every field describing who built the artifact is overwritten. Subjects and the build description
are kept as sent.

The token must be issued for the audience of the DevGuard API. In GitLab request it with:

  id_tokens:
    DEVGUARD_ID_TOKEN:
      aud: https://api.devguard.org

The result is a DSSE envelope - or a sigstore bundle, if DevGuard uploads to a transparency log.
Pass it to 'devguard-scanner attest' to attach it to an image: already signed input is attached as-is.
The first argument is a path to the provenance JSON file. Pass "-" to read from stdin.

```shell
devguard-scanner provenance sign <provenance> [flags]
```

### Examples

```shell
  # Sign the provenance generated by 'devguard-scanner intoto stop --generateSlsaProvenance'
  devguard-scanner provenance sign build.provenance.json --output build.provenance.dsse.json --token=$DEVGUARD_TOKEN --assetName=$DEVGUARD_ASSET_NAME

  # Attach the signed provenance to the image without signing it again
  devguard-scanner attest build.provenance.dsse.json ghcr.io/org/image:tag --predicateType https://slsa.dev/provenance/v1

  # Pass the token explicitly and print the signed provenance to stdout
  devguard-scanner provenance sign build.provenance.json --idToken="$MY_ID_TOKEN"
```

### Options

```shell
      --apiUrl string       The url of the API to send the scan request to (default "https://api.devguard.org")
      --assetName string    The id of the asset which is scanned
      --defaultRef string   The default git reference to use. This can be a branch, tag, or commit hash. If not specified, it will check, if the current directory is a git repo. If it isn't, --ref will be used.
  -h, --help                help for sign
      --idToken string      The OIDC workload identity token of the CI job. Defaults to the DEVGUARD_ID_TOKEN environment variable.
      --isTag               If the current git reference is a tag. If not specified, it will check if the current directory is a git repo. If it isn't, it will be set to false.
  -o, --output string       File to write the signed provenance to. Defaults to stdout.
      --ref string          The git reference to use. This can be a branch, tag, or commit hash. If not specified, it will first check for a git repository in the current directory. If not found, it will just use main.
      --token string        The personal access token to authenticate the request
```
